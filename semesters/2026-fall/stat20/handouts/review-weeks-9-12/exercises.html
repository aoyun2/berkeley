1. boot_stats

reps statistics, each stat applied to a resample of x (size length(x), with replacement). Returns a numeric vector. It must work when x has length 1.

Solution 
boot_stats <- function(x, stat, reps) {
  n <- length(x)
  replicate(reps, stat(x[sample.int(n, size = n, replace = TRUE)]))
}

2. percentile_ci

Percentile interval: the (1 - level)/2 and (1 + level)/2 quantiles of stats (use quantile() with its default type). Returns a length-2 numeric vector with no names.

Solution 
percentile_ci <- function(stats, level) {
  unname(quantile(stats, probs = c((1 - level) / 2, (1 + level) / 2)))
}

3. two_sided_p

Two-sided p-value from a null distribution, as infer computes it: twice the smaller of mean(null >= obs) and mean(null <= obs), capped at 1.

Solution 
two_sided_p <- function(null_stats, obs) {
  min(1, 2 * min(mean(null_stats >= obs), mean(null_stats <= obs)))
}

4. chisq_stat

Chi-squared statistic: observed counts and null proportions p (same order, p sums to 1).

Solution 
chisq_stat <- function(observed, p) {
  expected <- sum(observed) * p
  sum((observed - expected)^2 / expected)
}

5. ls_coef

Least squares line: c(b0, b1) from the formulas b1 = Sxy / Sxx, b0 = mean(y) - b1 * mean(x). If all x are equal, return c(mean(y), NA), as lm() does.

Solution 
ls_coef <- function(x, y) {
  sxx <- sum((x - mean(x))^2)
  if (sxx == 0) return(c(mean(y), NA))
  b1 <- sum((x - mean(x)) * (y - mean(y))) / sxx
  c(mean(y) - b1 * mean(x), b1)
}

6. r_squared

R² of predictions y_hat for targets y, with the baseline mean(y) taken from the same y (so it can be negative on a test set).

Solution 
r_squared <- function(y, y_hat) {
  1 - mean((y - y_hat)^2) / mean((y - mean(y))^2)
}

7. logistic, classify

Logistic function and classification with threshold 0.5 (p >= 0.5 -> 1).

Solution 
logistic <- function(t) {
  1 / (1 + exp(-t))
}
classify <- function(p_hat) {
  ifelse(p_hat >= 0.5, 1, 0)
}

8. metrics

Metrics for 0/1 vectors y and y_hat: a named vector c(mcr = , precision = , recall = ); 0/0 gives NaN.

Solution 
metrics <- function(y, y_hat) {
  tp <- sum(y == 1 & y_hat == 1)
  fp <- sum(y == 0 & y_hat == 1)
  fn <- sum(y == 1 & y_hat == 0)
  c(mcr = mean(y != y_hat), precision = tp / (tp + fp), recall = tp / (tp + fn))
}

9. perm_null

reps values of mean(y[g == "a"]) - mean(y[g == "b"]) where g is a shuffled copy of group (sample(group) keeps the group sizes). group has values "a" and "b".

Solution 
perm_null <- function(y, group, reps) {
  replicate(reps, {
    g <- sample(group)
    mean(y[g == "a"]) - mean(y[g == "b"])
  })
}

10. split_rows

Train/test split of rows 1..n: shuffle the row numbers, the first floor(n * frac) form the training set, the rest the test set. Returns list(train = , test = ) of row numbers; train may be empty.

Solution 
split_rows <- function(n, frac) {
  rows <- sample.int(n)
  k <- floor(n * frac)
  list(train = rows[seq_len(k)], test = rows[setdiff(seq_len(n), seq_len(k))])
}

11. binom_test_power

Exact size and power of the one-sided test of H0: p = p0 against HA: p > p0 with n tosses that rejects when X >= c, where c is the smallest count with P(X >= c | p0) <= alpha. Returns c(c = , size = , power = ) with power computed at p1. If no count qualifies, c is n + 1 and size and power are 0.

Solution 
binom_test_power <- function(n, p0, p1, alpha) {
  tail0 <- 1 - pbinom(0:n - 1, n, p0)
  ok <- which(tail0 <= alpha)
  if (length(ok) == 0) return(c(c = n + 1, size = 0, power = 0))
  k <- ok[1] - 1
  c(c = k, size = 1 - pbinom(k - 1, n, p0), power = 1 - pbinom(k - 1, n, p1))
}
