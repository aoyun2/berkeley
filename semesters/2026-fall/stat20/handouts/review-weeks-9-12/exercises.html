1. Bootstrap Statistics (boot_stats)

Not run
reps statistics, each stat applied to a resample of x (size length(x), with replacement). Returns a numeric vector. Must work when x has length 1.
Note: For a single number x, sample(x) draws from 1:x; index with sample.int(n, size = n, replace = TRUE) instead.
Tip: n <- length(x); replicate(reps, stat(x[sample.int(n, size = n, replace = TRUE)])) Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

boot_stats <- function(x, stat, reps) {
  n <- length(x)
  replicate(reps, stat(x[sample.int(n, size = n, replace = TRUE)]))
}

4. Chi-Squared Statistic (chisq_stat)

Not run
Observed counts and null proportions p (same order, p sums to 1). Formula: ∑ (observed - expected)² / expected where expected = sum(observed) * p.
Tip: Vectorized formula across all categories. Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

chisq_stat <- function(observed, p) {
  expected <- sum(observed) * p
  sum((observed - expected)^2 / expected)
}

5. Least Squares Coefficients (ls_coef)

Not run
Least squares line: c(b0, b1) from the formulas b1 = Sxy / Sxx, b0 = mean(y) - b1 * mean(x). If all x are equal (Sxx == 0), return c(mean(y), NA), as lm() does.
Tip: sxx <- sum((x - mean(x))^2); if (sxx == 0) return(c(mean(y), NA)) Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

ls_coef <- function(x, y) {
  sxx <- sum((x - mean(x))^2)
  if (sxx == 0) return(c(mean(y), NA))
  b1 <- sum((x - mean(x)) * (y - mean(y))) / sxx
  c(mean(y) - b1 * mean(x), b1)
}

}

8. Classification Metrics (metrics)

Not run
Metrics for 0/1 vectors y and y_hat: a named vector c(mcr = ..., precision = ..., recall = ...). Note: 0/0 gives NaN.
Tip: Calculate tp <- sum(y == 1 & y_hat == 1), fp, and fn. Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

metrics <- function(y, y_hat) {
  tp <- sum(y == 1 & y_hat == 1)
  fp <- sum(y == 0 & y_hat == 1)
  fn <- sum(y == 1 & y_hat == 0)
  c(mcr = mean(y != y_hat), precision = tp / (tp + fp), recall = tp / (tp + fn))
}

9. Permutation Null Distribution (perm_null)

perm_null <- function(y, group, reps) {
  replicate(reps, {
    g <- sample(group)
    mean(y[g == "a"]) - mean(y[g == "b"])
  })
}

10. Train/Test Row Split (split_rows)

Not run
Train/test split of rows 1..n: shuffle the row numbers, the first floor(n * frac) form the training set, the rest the test set. Returns list(train = ..., test = ...) of row numbers; train may be empty.
Tip: rows <- sample.int(n); k <- floor(n * frac); use seq_len(k). Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

split_rows <- function(n, frac) {
  rows <- sample.int(n)
  k <- floor(n * frac)
  list(train = rows[seq_len(k)], test = rows[setdiff(seq_len(n), seq_len(k))])
}

11. Binomial Test Size and Power (binom_test_power)

Not run
Exact size and power of the one-sided test of H0: p = p0 against HA: p > p0 with n tosses that rejects when X >= c, where c is the smallest count with P(X >= c | p0) <= alpha. Returns c(c = ..., size = ..., power = ...) with power computed at p1. If no count qualifies, c is n + 1 and size and power are 0.
Tip: P(X >= k) = 1 - pbinom(k - 1, n, p). Find the smallest k where tail ≤ alpha. Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

binom_test_power <- function(n, p0, p1, alpha) {
  tail0 <- 1 - pbinom(0:n - 1, n, p0)
  ok <- which(tail0 <= alpha)
  if (length(ok) == 0) return(c(c = n + 1, size = 0, power = 0))
  k <- ok[1] - 1
  c(c = k, size = 1 - pbinom(k - 1, n, p0), power = 1 - pbinom(k - 1, n, p1))
}
