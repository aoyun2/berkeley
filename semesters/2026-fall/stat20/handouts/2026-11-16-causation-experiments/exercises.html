1. ate

Average treatment effect of units whose two potential outcomes are known: y_c and y_t. For example, ate(c(3, 4, 2, 5), c(5, 4, 6, 7)) is 2.

Solution 
ate <- function(y_c, y_t) {
  mean(y_t - y_c)
}

2. diff_in_means

Difference in means, treated minus control. treated is TRUE/FALSE for each unit. For example, diff_in_means(c(5, 4, 2, 5), c(TRUE, TRUE, FALSE, FALSE)) is 1.

Solution 
diff_in_means <- function(y, treated) {
  mean(y[treated]) - mean(y[!treated])
}

3. all_estimates

Every estimate an experiment could produce: treat m of the n units in every possible way (combn), and return the vector of treated-minus-control differences, one per assignment. Unit i shows y_t[i] if treated and y_c[i] if not.

Solution 
all_estimates <- function(y_c, y_t, m) {
  n <- length(y_c)
  apply(combn(n, m), 2, function(idx) {
    treated <- seq_len(n) %in% idx
    mean(y_t[treated]) - mean(y_c[!treated])
  })
}

4. smd

Standardized mean difference of covariate x, treated minus control, with the pooled standard deviation sqrt(var_t / 2 + var_c / 2). If binary_std is TRUE, x is 0/1 and each group's variance is p * (1 - p) (as in cobalt's binary = "std"); otherwise use var() (n - 1).

Solution 
smd <- function(x, treated, binary_std = FALSE) {
  v <- function(z) if (binary_std) mean(z) * (1 - mean(z)) else var(z)
  (mean(x[treated]) - mean(x[!treated])) / sqrt(v(x[treated]) / 2 + v(x[!treated]) / 2)
}

5. exact_p_value

Exact two-sided balance-test p-value for covariate x: the null distribution is the difference in means over every assignment of sum(treated) units to treatment; take the tail on the side of the observed difference (>= if it is >= 0, else <=), double it, and cap at 1.

Solution 
exact_p_value <- function(x, treated) {
  obs <- diff_in_means(x, treated)
  n <- length(x)
  null <- apply(combn(n, sum(treated)), 2, function(idx) diff_in_means(x, seq_len(n) %in% idx))
  eps <- 1e-9
  tail <- if (obs >= 0) mean(null >= obs - eps) else mean(null <= obs + eps)
  min(1, 2 * tail)
}

6. prob_all_same_group

Probability that k special units all land in the same group when m of n units are treated at random (the treated group has m units, the control group n - m).

Solution 
prob_all_same_group <- function(n, m, k) {
  (choose(n - k, m - k) + choose(n - k, m)) / choose(n, m)
}
