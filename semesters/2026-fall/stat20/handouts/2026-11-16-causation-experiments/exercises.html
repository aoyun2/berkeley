1. Average Treatment Effect (ate)

Not run
Average treatment effect of units whose two potential outcomes are known: y_c (control) and y_t (treatment).
Example: ate(c(3, 4, 2, 5), c(5, 4, 6, 7)) is 2.
Tip: Return the mean difference across all units. Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

ate <- function(y_c, y_t) {
  mean(y_t - y_c)
}

2. Difference in Means (diff_in_means)

Not run
Difference in means, treated minus control. treated is a logical vector of TRUE/FALSE for each unit.
Example: diff_in_means(c(5, 4, 2, 5), c(TRUE, TRUE, FALSE, FALSE)) is 1.
Tip: Compute mean(y[treated]) - mean(y[!treated]). Ctrl+Enter to run
Reveal Solution

diff_in_means <- function(y, treated) {
  mean(y[treated]) - mean(y[!treated])
}

3. All Possible Estimates (all_estimates)

Not run
Every estimate an experiment could produce: treat m of the n units in every possible way (using combn), and return the vector of treated-minus-control differences, one per assignment. Unit i shows y_t[i] if treated and y_c[i] if not.
Tip: Use combn(n, m) and apply(..., 2, ...). Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

all_estimates <- function(y_c, y_t, m) {
  n <- length(y_c)
  apply(combn(n, m), 2, function(idx) {
    treated <- seq_len(n) %in% idx
    mean(y_t[treated]) - mean(y_c[!treated])
  })
}

4. Standardized Mean Difference (smd)

Not run
Standardized mean difference of covariate x, treated minus control, with the pooled standard deviation sqrt(var_t / 2 + var_c / 2). If binary_std is TRUE, x is 0/1 and each group's variance is p * (1 - p); otherwise use sample variance var() (n - 1).
Tip: Define a helper variance function that switches on binary_std. Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

smd <- function(x, treated, binary_std = FALSE) {
  v <- function(z) if (binary_std) mean(z) * (1 - mean(z)) else var(z)
  (mean(x[treated]) - mean(x[!treated])) / sqrt(v(x[treated]) / 2 + v(x[!treated]) / 2)
}

5. Exact Balance-Test P-Value (exact_p_value)

Not run
Exact two-sided balance-test p-value for covariate x: the null distribution is the difference in means over every assignment of sum(treated) units to treatment; take the tail on the side of the observed difference (>= if observed is >= 0, else <=), double it, and cap at 1.
Tip: Use diff_in_means, combn(n, sum(treated)), and min(1, 2 * tail). Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

exact_p_value <- function(x, treated) {
  obs <- diff_in_means(x, treated)
  n <- length(x)
  null <- apply(combn(n, sum(treated)), 2, function(idx) diff_in_means(x, seq_len(n) %in% idx))
  eps <- 1e-9
  tail <- if (obs >= 0) mean(null >= obs - eps) else mean(null <= obs + eps)
  min(1, 2 * tail)
}

6. Probability All in Same Group (prob_all_same_group)

Not run
Probability that k special units all land in the same group when m of n units are treated at random (the treated group has m units, control group n - m).
Tip: Combinatorics with choose(): treated or control. Ctrl+Enter to run
Reveal Solution

Look only after your function passes or you have spent 15 minutes stuck on this exercise.

prob_all_same_group <- function(n, m, k) {
  (choose(n - k, m - k) + choose(n - k, m)) / choose(n, m)
}
