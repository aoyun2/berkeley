The parser wraps each statement of a block and each arm of a
case
in an
At
that records the line it appeared on, so that an error raised while evaluating
that code can say where the code is. Those markers are part of the AST, but they
don’t affect the value of the code, so you can hide them to see its structure more
clearly.
This page only parses Gleam. It doesn’t evaluate anything, and it reads only the
subset of Gleam that the parser supports. A function shows as its name, its
parameters, and its body.
