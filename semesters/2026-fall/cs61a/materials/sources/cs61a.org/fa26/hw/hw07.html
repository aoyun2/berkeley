Setup

This homework is written in Gleam. To install Node.js and Gleam and set up VS Code for Gleam, follow the setup instructions in Lab 8. Download and open hw07 the same way you did lab08.

Test Your Code

From the Terminal menu within VS Code, select New Terminal, which opens a terminal pane at the bottom of your hw07 VS Code window. When you type ls, you should see gleam.toml, src, and test.

Run one question's tests by naming it after --, or run the whole suite with gleam test:

gleam test -- pow        # just this question
gleam test               # the whole suite
gleam test -- score      # every question, with your score

The tests will fail until you've solved the questions below. If something goes wrong, see What can go wrong? in Lab 8.

Run Your Gleam Code

The file you're editing ends with a main function, which gleam run calls:

gleam run

Right now, main just prints a message. You can add any Gleam code there you want, including calls to the functions in this assignment.

echo also works inside any other function, so you can print intermediate values while the tests run.

You can also test out Gleam code on the online Gleam Playground.

Q1: Powers

Implement a function pow that raises a number base to the power of a nonnegative integer exp just by using multiplication. It should be fast! For example, pow(2, 32) should result in 5 or 6 recursive pow calls rather than 32.

  1. x2y = (xy)2
  2. x2y+1 = x(xy)2

Q3: Minimize
