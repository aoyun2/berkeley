Recursion in Gleam

Gleam has no while or for statements, so repetition in Gleam is expressed with recursion. A case expression can choose between a base case and a recursive case.

For example, here's a function that computes n factorial for nonnegative n.

/// n * (n-1) * (n-2) * ... * 1
pub fn factorial(n: Int) -> Int {
  case n {
    0 -> 1
    _ -> n * factorial(n - 1)
  }
}

Q2: Summation

Section 1.6 of Composing Programs defines summation, which takes an upper bound n and a function term that computes the kth term, and returns the sum of term(k) for each k from 1 to n:

def summation(n, term):
    total, k = 0, 1
    while k <= n:
        total = total + term(k)
        k = k + 1
    return total

Q5: Sevens

The Game of Sevens: Players in a circle count up from 1 in the clockwise direction. (The starting player says 1, the player to their left says 2, etc.) If a number is divisible by 7 or contains a 7 (or both), switch directions.

For example, 5 people would count to 10 like this:

Player 1 says 1
Player 2 says 2
Player 3 says 3
Player 4 says 4
Player 5 says 5
Player 1 says 6  # All the way around the circle
Player 2 says 7  # Switch to counterclockwise
Player 1 says 8
Player 5 says 9  # Back around the circle counterclockwise
Player 4 says 10

Implement sevens, which takes a positive integer n and a number of players k. It returns which of the k players says n. You may call has_seven.

assert sevens(2, 5) == 2
assert sevens(6, 5) == 1
assert sevens(7, 5) == 2
assert sevens(8, 5) == 1
assert sevens(9, 5) == 5
assert sevens(18, 5) == 2

Gleam functions can't be defined inside other functions, so the simulation happens in a separate function play. It keeps track of the final number n, the number of players k, the current number i, the player who will say i, and the current direction that determines the next player (either 1 for increasing or -1 for decreasing).

/// Whether `n` contains the digit 7, where `n` is a nonnegative integer.
pub fn has_seven(n: Int) -> Bool {
  case n {
    0 -> False
    _ -> n % 10 == 7 || has_seven(n / 10)
  }
}

/// The (clockwise) position of who says `n` among `k` players.
pub fn sevens(n: Int, k: Int) -> Int {
  play(n, k, 1, 1, 1)
