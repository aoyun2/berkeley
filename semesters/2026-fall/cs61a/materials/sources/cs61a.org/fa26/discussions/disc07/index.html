Generators

A generator is an iterator that is returned by calling a generator function, which is a function that contains yield statements instead of return statements. The ways to use an iterator are to call next on it or to use it as an iterable (for example, in a for statement).

Q1: Big Fib

The generator function gen_fib (in the code below) yields all of the Fibonacci numbers.

Explain the following expression to each other so that everyone understands how it works. (It creates a list of the first 10 Fibonacci numbers.)

(lambda t: [next(t) for _ in range(10)])(gen_fib())

Then, complete the return expression of big_fib below by writing only names and parentheses in the blanks so that it evaluates to the smallest Fibonacci number that is larger than 2026.

Talk with each other about what built-in functions might be helpful, such as map, filter, list, any, all, etc. (Click on these function names to view their documentation.) Try to figure out the answer without using Python. Only run the code when your group agrees that the answer is right. This is not the time for guess-and-check.

def gen_fib() -> Iterator[int]:
    n, add = 0, 1
    while True:
        yield n
        n, add = n + add, n


def big_fib() -> int:
    """Return the smallest Fibonacci number that is larger than 2026.

    >>> big_fib()
    2584
    """
    return next(____(lambda n: n > 2026, ____))
Hint

One solution has the form: next(____(lambda n: n > 2026, ____)) where the first blank uses a built-in function to create an iterator over just large numbers and the second blank creates an iterator over all Fibonacci numbers.

Tree reminder

A Tree has a label and a list of branches, each of which is a Tree.

@dataclass
class Tree[T]:
    label: T
    branches: list[Tree[T]] = field(default_factory=list)  # branches defaults to []
