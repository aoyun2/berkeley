Lists in Gleam

A Gleam list is either empty ([]) or a first element followed by the rest of the list ([first, ..rest]). A case expression can match these patterns to choose between a base case and a recursive case.

For example, here's a function that sums a list of numbers.

/// The sum of the elements of s.
pub fn sum(s: List(Int)) -> Int {
  case s {
    [] -> 0
    [first, ..rest] -> first + sum(rest)
  }
}

Q3: Find Repeated

A function that might not successfully return a value can return a Result, which is either Ok(value) or an Error. Error(Nil) means there is no additional data about the error (which is common).

Implement find_repeated, which takes a list s and a positive integer n. It returns Ok(x), where x is the first item to appear at least n times, or Error(Nil) if no item appears n or more times.

assert find_repeated([1, 2, 2, 1], 2) == Ok(2)  // 2 appears twice before 1 does
assert find_repeated([1, 2, 3], 2) == Error(Nil)

Its helper finder keeps track of how many times each item has appeared using a Dict. Here are the only functions you need:

  • dict.new() returns an empty Dict.
  • dict.get(d, key) returns Ok(value) if key is stored in d with value, or Error(Nil) if it isn't.
  • dict.insert(d, key, value) returns a new Dict that also stores value for key, replacing any value stored there before. It doesn't change d.
let counts = dict.insert(dict.new(), "a", 1)
assert dict.get(counts, "a") == Ok(1)
assert dict.get(counts, "b") == Error(Nil)

Q4: Email

An email system has one server, which stores each person's inbox and a list of emails it could not deliver. Gleam values are immutable, so sending an email can't change an inbox. Instead, each function below takes a Server and returns a new Server.

pub type Email {
  Email(msg: String, from: String, to: String)
}

pub type Inbox {
  Inbox(owner: String, emails: List(Email))
}

pub type Server {
  Server(boxes: Dict(String, Inbox), undelivered: List(Email))
}

A record update creates a new record that copies an existing record's fields, except the ones it names. For example, Inbox(..inbox, emails: []) is an Inbox with the same owner as inbox and no emails. Use record updates in add_inbox and send.

let server = Server(dict.new(), [])
let server = add_inbox(server, "eumaeus")
let server = add_inbox(server, "odysseus")

let ask = Email("Bringing vengeance?", "eumaeus", "odysseus")
let server = send(server, ask)
assert dict.get(server.boxes, "odysseus") == Ok(Inbox("odysseus", [ask]))

let server = respond(server, ask, "Bringing it all!")
let reply = Email("Bringing it all!", "odysseus", "eumaeus")
assert dict.get(server.boxes, "eumaeus") == Ok(Inbox("eumaeus", [reply]))
