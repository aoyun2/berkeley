Trees

A Tree has a label and a list of branches, each of which is a Tree. A tree with no branches is called a leaf.

@dataclass
class Tree[T]:
    label: T
    branches: list[Tree[T]] = field(default_factory=list)  # branches defaults to []

def is_leaf(t: Tree) -> bool:
    "Return whether a Tree t is a leaf with no branches."
    return not t.branches

For example:

  • Tree(4) makes a leaf labeled 4.
  • u = Tree(5, [Tree(6), Tree(7)]) makes a tree labeled 5 with two leaves labeled 6 and 7.
  • t = Tree(3, [Tree(4), u]) makes a tree labeled 3 with two branches: a leaf labeled 4 and the tree u.

Printing a Tree shows each label on its own line, indented below its parent's label:

>>> u = Tree(5, [Tree(6), Tree(7)])
>>> t = Tree(3, [Tree(4), u])
>>> print(t)
3
  4
  5
    6
    7

The label of the second branch of t is t.branches[1].label, which is 5.

A node of Tree t is either itself or a Tree within it. A node's parent is the Tree for which it is a branch, and its children are its branches. The root node is t and has no parent. Leaves have no children. A path is a sequence of nodes in which each is the parent of the next.

This tree visualizer draws the structure of any tree.

Remember, for a tree t:

  • Its root label t.label can be any value.
  • Its branches are trees, and t.branches is a list of its branches.
  • An equivalent tree can be constructed with Tree(t.label, t.branches).
  • To check whether a tree t is a leaf, call is_leaf(t).
  • You can call functions that take a tree as an argument, such as sum_leaves(t).
def sum_leaves(t: Tree[int]) -> int:
    """Return the sum of the labels of the leaves of tree t.

    >>> t = Tree(3, [Tree(4), Tree(5, [Tree(6), Tree(7)])])
    >>> sum_leaves(t)  # 4 + 6 + 7
    17
    """
    if is_leaf(t):  # if t is a leaf,
        return t.label  # then the sum of its leaf labels is just its label
    return sum([sum_leaves(b) for b in t.branches])

The type Tree[int] describes a tree whose labels are all integers.

A type variable, such as T below, represents any type and expresses that the return value has the same type as the labels of the input tree.

def largest_leaf[T](t: Tree[T]) -> T:
    """Return the largest label of the leaves of tree t.

    >>> t = Tree(3, [Tree(4), Tree(5, [Tree(6), Tree(7)])])
    >>> largest_leaf(t)
    7
    """
    if is_leaf(t):  # if t is a leaf,
        return t.label  # then the largest leaf label is just its label
    return max([largest_leaf(b) for b in t.branches])

Q1: Warm Up

What value is bound to result?

def label(t: Tree[int]) -> int:
    return t.label

u = Tree(5, [Tree(6), Tree(7)])
t = Tree(3, [Tree(4), u])
result = min(max([t, u], key=label).branches, key=label).label

How convoluted! (That's a big word.)

What does key do?

Here's a quick refresher on how key functions work with max and min.

max(s, key=f) returns the item x in s for which f(x) is largest.

>>> s = [-3, -5, -4, -1, -2]
>>> max(s)
-1
>>> max(s, key=abs)
-5
>>> max([abs(x) for x in s])
5

Therefore, max([t, u], key=label) returns the tree with the largest label, in this case u.

Q2: Has Path

Implement has_path, which takes a tree t and a list p. It returns whether there is a path from the root of t with labels p. For example, t has a path from its root with labels [3, 5, 6] but not [3, 4, 6] or [5, 6].

Important: Before trying to implement this function, discuss these questions from lecture about the recursive call of a tree processing function:

  • What small initial choice can I make (such as which branch to explore)?
  • What recursive call should I make for each option?
  • How can I combine the results of those recursive calls?
    • What type of values do they return?
    • What do those return values mean?

If you get stuck, you can view our answers to these questions by clicking the hint button below, but please don't do that until your whole group agrees.

Big Hint: Describing the Recursive Call

What small initial choice can I make (such as which branch to explore)?

Choose each one of the branches and call it b.

What recursive call should I make for each branch?

Call has_path on each branch b. You'll make this call after comparing p[0] to t.label, and so the second argument to has_path will be the rest of p: has_path(b, p[1:]).

What type of values do they return?

has_path always returns a bool value: True or False.

What do the possible return values mean?

If has_path(b, p[1:]) returns True, then there is a path through branch b for which p[1:] are the node labels.

How can I combine the results of those recursive calls?

If you have already checked that t.label is equal to p[0], then a True return value from the recursive call has_path(b, p[1:]) means there is a path through t with labels p using that branch b, so return. A False value means there is no path through that branch, but there might be path through a different branch, so don't return yet.

Q3: Find Path

Implement find_path, which takes a tree t with unique labels and a value x. It returns a list containing the labels of the nodes along a path from the root of t to a node labeled x.

If x is not a label in t, return None. Assume that the labels of t are unique.

First talk through how to make and use the recursive call. (Try it yourselves; don't just click the hint button. That's how you learn.)

Big Hint: Describing the Recursive Call

What small initial choice can I make (such as which branch to explore)?

Choose each one of the branches and call it b.

What recursive call should I make for each branch?

find_path(b, x) on each branch b.

What type of values do they return?

Each recursive call will either return None or a non-empty list of node labels.

What do the possible return values mean?

If find_path(b, x) returns None, then x does not appear in b. If find_path(b, x) returns a list, then it contains the node labels for a path through b that ends with the node labeled x.

How can you use those return values to complete your implementation?

If a list is returned, then it contains all of the labels in the path except t.label, which must be placed at the front.
