Functional Programming
Perspective on Programming

Imperative: Programs are instructions for updating memory

Object-oriented: Programs define objects that behave like entities they represent

Functional: Programs are data definitions and pure functions that generate data

These aren't mutually exclusive, and ideas from each perspective can be combined

The Gleam Language
Some characteristics of Gleam that make it a functional language:

• Program behavior is just functions, and function bodies are expressions

• Functions are first-class values that can be passed as arguments and returned

• Anonymous functions are convenient to create and used liberally

• All values are immutable (and no for/while loops that update variables)


Why learn Gleam in particular?

• It's small & simple: only functions, names, and one form of conditional (case)

• A nice language for learning about algebraic data types and pattern matching

• Great preparation for learning Rust, Swift, and Typescript (which are larger)

The body of Gleam functions are all expressions, which can be:

• Let expressions:              let x = 4

Blocks
Blocks

Blocks can contain multiple lines, and they evaluate to the value of their last expression

A let within a block does not affect expressions outside the block

Blocks are used to change the order of evaluation in arithmetic (instead of parentheses)

  /// Compute a*x*x + b*x + c
  pub fn quadratic(x: Int, a: Int, b: Int, c: Int) -> Int {
    let ax2 = {
      let x2 = x * x
      a * x2
    }

      // ax2 is in scope here, but x2 is not
      ax2 + b * x + c
  }

Compiling Gleam
Gleam is compiled (checked and translated) into either Javascript or Erlang.

When compiling to Javascript, which is not tail-recursive, it generates while loops for
recursive tail calls.

Generic Functions
Generic Functions Take Multiple Types of Values

A lowercase type name is a placeholder for the actual type used to call a function.

   pub fn main() {
     let add_one = fn(x) { x + 1 }
     let exclaim = fn(x) { x <> "!" }

       echo twice(add_one, 10)
       echo twice(exclaim, "Hello")
   }

   // The name t refers to the same type multiple times          // Also works:
   fn twice(f: fn(t) -> t, x: t) -> t {                          fn twice(f, x) {
     f(f(x))                                                       f(f(x))
   }                                                             }

which calls f repeatedly k times on x.
For example, k_times(add_one, 10, 3) evaluates add_one(add_one(add_one(10)))
