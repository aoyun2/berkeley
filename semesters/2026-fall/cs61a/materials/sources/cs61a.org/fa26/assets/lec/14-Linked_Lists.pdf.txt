How to Work with Linked Lists

For a LinkedList s, check if it's a Link before accessing its first and/or rest attributes
   if isinstance(s, Link):                   if not isinstance(s, Link):
       ...                                       ...
                   In here you can access    else:
                     s.first and s.rest          ...
                                                           Also in here

Each time you call Link on 2 arguments, the second operand must evaluate to a linked list!
• Link(4, ()) or Link(4, Link(...))
• Link(4, s) as long as s is a name for a linked list
• Link(4, f(...)) as long as f returns a linked list

Construct the rest of the linked list, then add to the front:   3      4       5 /
   >>> s = ()
                                                          Link(3, Link(4, Link(5)))
   >>> s = Link(5, s)
   >>> s = Link(4, s)
   >>> s = Link(3, s)
   >>> print(s)
   (3 4 5)
