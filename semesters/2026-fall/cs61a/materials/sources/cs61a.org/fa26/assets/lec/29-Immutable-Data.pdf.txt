     Last(_) -> True

Results

The built-in Result type is used for value-based error handling

In Python, most code is written assuming no errors occur, and error handling is optional

  >>> s = [3, 4]
  >>> s[5]
  Traceback (most recent call last):
    File "<python-input-2>", line 1, in <module>
      s[5]
      ~^^^
  IndexError: list index out of range

Gleam programs do not run until the compiler confirms that all errors are handled

Creating and Processing Results

To create a result, write Ok(...) or Error(...)

To process a result, write:

case some_expression_that_evaluates_to_a_result {
  Ok(...) -> ...
  Error(...) -> ...
}

There are convenience functions for working with results in the Gleam standard library

list.try_map takes a function that returns a Result and applies it to each item in a list,
returning a list of Ok values or the first Error.

int.parse has the signature: pub fn parse(string: String) -> Result(Int, Nil)

list.try_map(["1", "2", "3"], int.parse)     // Evaluates to Ok([1, 2, 3])
list.try_map(["1", "two", "3"], int.parse)   // Evaluates to Error(Nil) because of "two"
