# Week 3 exercises (CS 61A)

Original exercises on lambda, currying, zero-argument functions and exam-style iteration.

1. `week03.py`: fill in each function. Where the docstring says "one lambda expression", the answer is a single `return lambda ...` line.
2. `predict.py`: write what each snippet displays when run as a file.
3. `timed.py`: three exam-style problems. Set a timer for 25 minutes, write the answers ON PAPER first, then type them in and run the tests.

From this folder:

    python3 tests.py
    python3 -m doctest week03.py timed.py
