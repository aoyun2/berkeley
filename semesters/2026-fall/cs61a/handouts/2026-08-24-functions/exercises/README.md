# Week 1 exercises (CS 61A)

Original exercises on this week's ideas. Write them yourself, without AI help, the same way you would a lab.

1. `week01.py`: fill in each function where it says `YOUR CODE HERE`. This week has only expressions, `def`, `return` and `print`, so no `if` or `while` is needed (or allowed).
2. `predict.py`: for each snippet, write what running it as a file would display, before running anything.

Check your work from this folder:

    python3 tests.py            # checks week01.py and predict.py
    python3 -m doctest week01.py

Solutions are in `../solutions/`. Look only after `tests.py` passes or you have spent 15 minutes stuck on one problem.
