# Week 1 exercises (CS 61A)

Original Python exercises for Week 1 (expressions, functions, `return` vs `print`, composition).

## Learning objectives
- Distinguish returning a value from printing output to stdout.
- Compose arithmetic and selector expressions cleanly without unnecessary temporary state.
- Handle integer, negative, zero, and boundary inputs according to the stated domain.

## Setup and checks
Requires Python 3.8+ (standard library only). From this folder run:

    python3 tests.py
    python3 tests.py ../solutions

Solutions live in `../solutions/week01.py`. Work through each task before consulting them.
