E1. Long books

Not run
Titles of books with more than 260 pages, longest first.
Tip: Use where and order by ... desc. You can write either select ... or create table e1 as select ...; Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e1 as
  select title from books where pages > 260 order by pages desc;

E2. Prolific authors

Not run
Each author with number of books and total pages (authors with at least two books), by author.
Tip: Use group by author having count(*) >= 2 order by author. Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e2 as
  select author, count(*) as n, sum(pages) as total from books
    group by author having count(*) >= 2 order by author;

E3. Loan details

Not run
For each loan: member, title, author.
Tip: Join loans with books on title. Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e3 as
  select member, l.title, author from loans as l join books as b on l.title = b.title;

E4. Pairs of books

Not run
Pairs of different books by the same author, each pair once.
Tip: Self-join books as a, books as b where authors match and a.title < b.title. Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e4 as
  select a.title as first, b.title as second from books as a, books as b
    where a.author = b.author and a.title < b.title;

E5. Most loan days

Not run
The member with the most total loan days, and the total.
Tip: Group by member, order by total desc, and limit 1. Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e5 as
  select member, sum(days) as total from loans group by member order by total desc limit 1;

E6. Authors with multiple borrowers

Not run
Authors whose books were borrowed by at least two different members.
Tip: Join books and loans, group by author, having count(distinct member) >= 2. Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e6 as
  select author from books as b join loans as l on b.title = l.title
    group by author having count(distinct member) >= 2;

E7. Books by decade

Not run
Decade of each book with the number of books from it, oldest first.
Tip: Calculate decade with integer division: year/10*10 as decade. Ctrl+Enter to run
Reveal Solution

Look only after your query passes or you have spent 15 minutes stuck on this exercise.

create table e7 as
  select year/10*10 as decade, count(*) as n from books group by decade order by decade;
