# Berkeley

Courses, materials and weekly handouts for my courses at UC Berkeley, starting Fall 2026.

[Website](https://aoyun2.github.io/berkeley)

**How it works.** Every Saturday morning Claude reads each active course's schedule (`course.toml`), builds the handout for the coming week's homework, saves it under that course's `handouts/` folder, and sends it. Before exams it sends a review plan and review handouts.

- New semester: make a folder per course under `semesters/`, add the syllabus to `materials/`, and ask Claude to fill in `course.toml`.
- During the term: drop new homework, notes and practice exams into each course's `materials/` folder.

See `CLAUDE.md` for the details Claude follows and `standards/handout-standard.md` for the handout rules.
